# Shig Production Setup

This guide describes a complete single-server production setup for Shig.

Replace domains, usernames, passwords, tokens, and paths where needed. The examples use:

- `example.com` and `www.example.com` for the web client
- `relay.example.com` for the relay
- `/opt/shig` for the backend
- `/var/www/shig-web` for the Angular web client
- `thost` as deployment user
- `shig` as runtime user
